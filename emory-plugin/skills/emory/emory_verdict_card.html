ROOT CAUSE

Onboarding load for dealer 63237 (AU423D75, live 2026-09-21) created DEALER_PRODUCT_CODE rows for all 21 program-20285 products but applied rate systems (V_Rate_System_Application) to only 19; AUGP (AU PP GAP) and AUPL (AU PP GAP Plus) have none, so GAP is silently dropped from the 200 SUCCESS response. Only exclusion on AUGP/AUPL in Program_Product_Eligibility is DEMO, so a New/FINANCE deal is eligible. Other WA Audi dealers use AUGP WA / AUPL WA (5 dealers each); both have 24 active RATE_SKU_VCI rows on 2026-09-23, terms 12-96.
QPTR/QPTS: V_PROGRAM_VEHICLE_CLASS carries Make AUDI / Model ALL MODELS / EXCLUDED, eff 2020-01-22 to 9999-12-31. QPVS: every Audi class row is expired; only exclusions remain. QualityProtect is the competitive-make sibling of the VCI line; Audi vehicles are served by AUTR/AUTS/AUVS, which returned. Matches pattern library #23 (partial rate-system sync on onboarding).
